💳 Basic ATM Machine (Java)

A simple **ATM simulation system** built using Java.
This project demonstrates basic programming concepts like loops, conditions, user input handling, and modular methods.

🚀 Features

* 💰 Withdraw Money
* ➕ Deposit Money
* 📊 Check Account Balance
* ✅ Input Validation (prevents invalid amounts)
* 🔁 Continuous operation using loop (ATM-like behavior)

 🛠️ Technologies Used

* ->Java
* ->Scanner (for user input)

 ▶️ How to Run

1. Open terminal in project folder
2. Compile the program:
    javac src/ATM.java
   
3. Run the program:
    java -cp src ATM
